# Example structures

These deposited PDB coordinate files serve as upload examples and test fixtures.
They are included so tests can run without downloading data or relying on the
original research workspace.

| File | Use |
| --- | --- |
| `1IAR.pdb` | IL-4 / IL-4Rα example, pocket geometry checks, and browser smoke test |
| `3BPN.pdb` | IL-4 ternary complex, interface/contact regression tests, and standalone contact map |
| `3BPO.pdb` | IL-13 ternary complex, metadata checks, and standalone IL-13 contact map |

The structures come from the Protein Data Bank. The app accepts additional
PDB/mmCIF uploads and can retrieve other entries directly from RCSB.
